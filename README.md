# 🐍 Classic Snake Game - Python Turtle Graphics

An interactive implementation of the classic Snake Game built using Python's standard `turtle` library.
## 📦 Exporting to a Standalone Executable (.exe)
If you want to package this game into a standalone executable so it can run without Python installed, you can use **PyInstaller**:

1. Install PyInstaller:
   ```bash
   pip install pyinstaller

## 🌟 Features
- **Interactive Controls:** Smooth keyboard navigation using arrow keys (`Up`, `Down`, `Left`, `Right`).
- **Dynamic Scoring:** Real-time score updates and persistent High-Score tracking.
- **Tail Growth Mechanics:** The snake's body grows longer dynamically every time it eats food.
- **Collision Detection:** Robust boundary and self-collision algorithms that handle game-over and reset states.

## 🛠️ Requirements
- Python 3.x (No external libraries required; uses the built-in `turtle` module).

## 🚀 How to Run
1. Clone or download this repository.
2. Open your terminal or command prompt inside the project folder.
3. Run the script:
   ```bash
   python snake_game.py
